# 安全与隐私

## 私人数据

- 根目录 `.local/` 只存本机私人文件；必须 Git 忽略且排除安装包。Git 忽略不等于打包排除，两项都要验证。
- 书签使用 `.local/bookmarks.json`；示例只能含虚构公共数据。不要为了调试、生成文档或测试读取私人书签内容。
- 不把个人网址、备注、家庭清单、健康记录、账目放入源码、测试快照、截图、日志或提交记录。
- 清单默认保留 `~/.dsh/outing-checklist.json`。备份和迁移需要明确授权，测试使用临时目录，不改正式数据。
- 只给本人使用不意味着可以省略登录鉴权、输入验证、路径限制或资源预算。

## 凭据

产品功能的凭据属于后端，不能进入客户端 bundle、浏览器持久化、源码、普通配置、API 完整响应或日志。需要通过 DSH 进行交互式登录、绑定、获取令牌时，优先采用 DSH `credentials` service；使用前查询当前服务契约，不自行发明存储接口。开发用的实页预览工具是唯一例外：它把本机 GUI 登录状态保存在 `~/tools/pocket-kit-preview/state/`（目录 700、文件 600），仅用于本地截图，不随项目分发；详见[实页预览](browser-preview.md)。

书签备注不是凭据保险箱。客户端只获取展示和操作所需的非敏感信息；使用凭据访问第三方服务时由后端执行，并对错误、调试信息与审计输出脱敏。

## 接口与资源

- 通过 DSH Connection 注册路由并复用其认证机制；不另开未鉴权端口。
- 写操作验证方法、内容类型、请求头和输入大小；客户端校验不能替代后端校验。
- 外部链接、图标、文件路径、导入数据均是不可信输入。限制协议与读取范围，不将内容作为 HTML 或命令直接执行。
- 上传、下载及未来预览转换要有超时、大小 / 并发限制和取消；涉及第三方下载另行分析 SSRF、重定向和磁盘配额。
- 日志记录必要的错误码与脱敏上下文，不回显原始文件、凭据或完整请求体。
- 健康与记账分别使用独立私有目录、SQLite快照/原始账单备份和导出策略；同一个包不意味着混用数据。

## 现有功能边界

- 书签接口会将书签发给已登录浏览器；因此书签不能承载秘密。
- 测速使用随机测试数据、流式丢弃上传，不读取用户文件，也不存测试历史；仍消耗真实流量。
- 清单为 DSH 所有者共享，而非按会话隔离；revision 防止陈旧覆盖，不是权限机制。文件写队列为进程内机制，不支持多个独立进程同时写一份文件。

新增或改变数据流时同步更新对应[功能文档模板](features/_template.md)中的数据、安全与验证段落。本文件是规范，不声称所有未来实现已满足它。

## 1.3.0 五模块落地

健康、账单、进京证与文件配置已迁入.local/data；终端继续引用既有tmux会话。实际文件根目录不复制、不扩大默认授权。进京证凭据只回传配置布尔状态，迁移后暂停自动办理。文件写操作/根授权与终端指令只在用户UI完成，Agent仍须使用受DSH沙箱与审批约束的工具。匿名分享不因迁移而开放。细节和剩余边界见[五模块迁移记录](utilities-migration.md)。
