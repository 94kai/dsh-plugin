# 移动端规范（手机主用）

以下是新增和修改 UI 的验收要求，不是对当前界面已通过验收的声明。

## 布局与触控

- 必查 CSS 视口宽度：**320、375、390、430px**。窄屏不能出现整页横向溢出；表格、图表确需横向滚动时应限于明确的内容容器。
- 可交互目标至少 **44 × 44 CSS px**；图标可以小，但点击区域不能小。关闭、菜单、排序、删除、复选项同样适用。
- 主要动作无需 hover 即可发现和操作；hover 只作增强，不作为显示编辑、删除或说明的唯一方式。
- 保持按钮间距，避免相邻危险操作误触；删除、重置等动作有明确说明与确认。
- 页面继承 DSH 主题、字体和宿主布局，不擅自覆盖整个 app 的样式。

## 共享导航与弹窗

- 各工具页统一使用「返回会话 / 返回首页」按钮，手机端至少44px高、等宽排列；首页只保留「返回会话」。按钮使用宿主主题变量，不另写硬编码明暗色。
- 音乐信息编辑、匹配结果、移动和目标目录使用 `position:fixed` 遮罩弹窗，卡片限制在 `100dvh` 内，标题栏、关闭按钮和底部操作栏固定，只有中间内容区滚动；支持 Escape、点击遮罩和关闭按钮。移动端底栏两列，主操作占满一行。打开后焦点移到关闭按钮，关闭后回到原页面。
- 2026-11-07 已在390px与暗色实页查看，并复跑320/375/430px；未做真实Safari、软键盘和系统大字体验收。

## 视口、刘海与键盘

- 处理 `env(safe-area-inset-*)`，特别是底部动作区、浮层关闭按钮与横屏边缘；避免与宿主重复叠加安全区。
- 弹层高度使用适当的动态视口单位（如 `dvh`）及回退，不只依赖 `100vh`；内容过长时能滚动，关闭与提交保持可达。
- 真机检查地址栏展开 / 收起、屏幕旋转、软键盘弹出和收起。输入焦点、错误提示和提交按钮不能被键盘遮住；不强行锁住页面导致无法滚动。
- 表单提供明确 label、合适的输入类型和键盘操作；提交失败保留输入，防止重复提交。

## 长内容与状态

- 长网址、中文物品名、无空格字符串、备注、翻译文案和大数值都要可换行；flex/grid 子项注意 `min-width: 0`。
- 不用省略号永久隐藏必须辨识的信息；提供可访问的完整内容查看方式。
- 覆盖加载、空数据、无筛选结果、保存中、离线、登录失效、服务端错误、冲突和重试状态。
- 错误说明要告诉用户下一步，不只展示红色；异步结果使用合适的 `status` / `alert` 语义。
- 保留清晰焦点、可读名称和键盘导航；弹层关闭恢复合理焦点，减少动态效果并尊重 reduced-motion。

## 验证记录

每功能文档记录实际设备 / 浏览器、四个宽度覆盖、长文数据、软键盘、异常路径和未验证项目。响应式 CSS、静态截图、Node 测试或 happy-dom 单独通过，都不证明真机键盘、safe area 与浏览器布局通过。

三个模块已添加手机/coarse 44px 触控区、清单操作第二行、16px 输入、dvh 弹层、safe area 和长文换行。手机样式测试只检查规则存在，不测量布局；真机、软键盘与视觉验收尚未完成，详见[迁移验证记录](migration.md)。
