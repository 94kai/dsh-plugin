# 快捷访问

## 用途与入口

快捷链接集中在[首页](home.md)，点击网站在新标签页打开；首页「管理链接」打开原 `shortcuts` 主面板，支持新增、编辑、说明、备注和复制，返回按钮回首页。新增和每张卡片的编辑按钮始终可见，不依赖 hover；编辑为页内表单，不新增弹窗或独立插件。

旧「随身工具箱」侧栏弹出菜单和 `local.shortcuts.menu.action` 已移除。底部唯一自定义入口由首页模块提供，书签模块只保留详情页与数据接口。

## API 与数据

- `GET /api/shortcuts/bookmarks`：返回 `{ items, revision }`，revision 为文件原始内容的 SHA256；缺失文件返回空数组；畸形内容或其他读取失败返回 500 `{ error }`。经 DSH Connection 鉴权，不缓存响应。
- `POST /api/shortcuts/bookmarks`：JSON `{ action: 'add' | 'update', revision, id?, title, url, description, notes, color }`；新增由后端生成 UUID，编辑保留 ID、顺序、原图标与磁盘未知字段，未知字段仍不返回浏览器。不支持删除、排序或图标上传。标题/网址/说明/备注/背景色上限分别为 200/8192/1000/20000/100 字符，背景色为空或六位十六进制；最多 2000 项。
- 写请求要求 `X-Pocket-Kit: 1`、JSON 内容类型和同源 Fetch Metadata（如有），正文最多 64 KiB。错误 `{ error }`：400 输入错误、403 跨源/缺请求头、404 入口不存在、409 版本冲突、413 过大、415 类型错误、500 存储失败。冲突不自动覆盖，保留表单输入，需取消并刷新后重新编辑。
- 书签位置为根目录 `.local/bookmarks.json`，只在后端读写，维持顶层数组，无格式迁移；写入采用同目录独占临时文件、fsync 后原子替换，文件权限 0600，新建目录 0700。按绝对路径共享进程内写队列；revision 防止多浏览器陈旧覆盖，不是跨进程文件锁，不支持外部进程并行写文件。1.0.0 迁移保留内容字节一致并设为 0600，详见[迁移记录](../migration.md)。
- JSON 顶层数组，稳定且唯一的 `id`、非空 `title`、`url` 为必要展示字段。API 只返回白名单字段，另可含 `description`、`notes`、`color`、受限的 base64 图片 `iconDataUrl`。URL 仅允许 HTTP(S)，拒绝 URL 内用户名/密码；未知字段不发往客户端。
- API 将内容发送到已登录浏览器；备注不得存密码、令牌或其他秘密。`.local/` 需要同时 Git 忽略与打包排除。

### 图标兼容

支持 base64 内嵌 PNG、JPEG、WebP、GIF、SVG，以及 ICO 的 `image/x-icon` / `image/vnd.microsoft.icon` MIME。1.0.1 修复了合包白名单遗漏 ICO 导致飞牛书签图标消失的问题；不要只按常见位图扩展名过滤浏览器本来支持的 favicon。回归测试覆盖两种 ICO MIME。原图标字节保持不变，不把私人图标写入公开测试夹具。

## 决策与生命周期

新增与编辑只通过已鉴权写接口保存；损坏文件拒绝写入，不以空数组覆盖。表单失败保留输入，保存中阻止重复提交，卸载取消请求；请求发出后取消不保证撤回已经完成的保存，需刷新确认。取消/Escape/保存后恢复触发按钮焦点。详情主面板保留 `shortcuts` 标识，首页复用同一数据接口；保存后发送不带数据的 `pocket-kit:bookmarks-changed` 事件，让仍挂载的首页重新获取，监听在卸载时移除。

客户端获取数据使用 AbortController，卸载取消请求；不再维护弹出菜单监听。复制失败提供手工选择提示。未来修改应继续处理关闭后焦点恢复、请求过期及卸载后的状态更新。

## 验证与限制

合包验证已覆盖书签展示字段白名单、协议限制及统一客户端注册，具体结果见[迁移记录](../migration.md)。真实浏览器仍需刷新后检查入口和交互。后端独立停用时，统一客户端仍显示入口并报不可用。

回归重点：缺失/无效书签、空数组、加载失败重试、长标题和备注、复制失败、新标签页安全、首页入口及键盘导航；320/375/390/430px、44px 触控和 safe area 按[移动规范](../mobile.md)检查。已添加移动触控适配，但样式测试不等于视觉验证。
