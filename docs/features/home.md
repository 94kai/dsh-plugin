# 首页与统一导航（1.2.0）

## 页面与入口

首页是 Pocket Kit 的导航页，主面板 key 为 `pocket-kit.home`。左侧栏底部 `sidebar.footer.action` 中仅保留 `pocket-kit-home`「首页」按钮，替换旧「随身工具箱」弹出菜单。

首页集中显示：

- 音乐、小爱音箱、出门清单、连接测速四个工具入口；点击只打开页面或测速弹层，不触发下载、播放或测速。
- 现有快捷链接及其原图标、标题和说明；网站在新标签页打开，带 `noopener noreferrer`。
- 「详情与备注」仍进入原 `shortcuts` 主面板，保留复制网址、备注能力；首页不铺开私人备注。
- 「返回对话」进入 Conversation，不创建、删除或切换 Session。

清单、音乐和小爱不再注册 `sidebar.panellist` 重复入口。各工具原主面板 key、服务端 API 与数据保持不变，各工具页提供「返回会话 / 返回首页」；底部「工具箱」入口回到上次访问的正常工具页，而不是每次都回首页。DSH 自带插件管理、计划任务等宿主入口不在本次自定义入口清理范围内。

## 默认打开策略

从站点裸入口打开或刷新页面，首次挂载且当前为Conversation时会默认选择首页；即使宿主已恢复上次会话，也不改变、释放或删除该Session，点击返回对话仍可继续。

使用当前document上的 `Symbol.for('pocket-kit.home.startup.v1')` 记录一次机会，卸载不删除标记。同一页面的插件热重载、Slot重声明不会反复切回首页；完整刷新得到新的document，再按规则选择首页。首次热安装到裸URL且正在Conversation时也可能切首页，这是本次默认导航变更的预期效果。

显式query/hash/非入口路径、已经打开的非空全局面板保守保留，避免覆盖深链接或用户刚完成的导航。子路径部署通过显式base标签识别入口。失败时不轮询重试，不在用户后续操作时抢页面。

当前已核验的layout配置和公开导航接口没有initialPanel或navigation-ready契约，因此使用已注册main后的 `layout.selectPanel()`；没有读写宿主私有localStorage，没有调用私有恢复方法。宿主启动恢复会保留已选全局panel，但selectPanel会使此前异步导航的UI提交失效，不能宣称没有任何导航副作用。浏览器启动时序仍需实页刷新验收。

## 扩展契约

首页 `main` 条目声明 root/list Slot：`local.pocket-kit.home.tool`，注册顺序决定卡片顺序。

子功能使用 `ctx.slots.inject('local.pocket-kit.home.tool', () => ctx.slots.register(...))` 贡献组件。组件接收 `renderCard({id,title,description,icon,onClick})`；可选稳定业务 `id` 由首页映射统一中文名称、简短说明和图标色，未知工具保留传入文案。首页统一渲染可访问的按钮、图标和说明。子功能只负责自己的导航或打开动作，不读写首页 DOM，不把业务状态放进首页。

当前顺序为音乐10、小爱20、清单30、测速40。测速原 `local.shortcuts.menu.action` 插槽已在1.2.0退役，未来入口统一接首页 Slot；`shell.overlay` 测速浮层保持原标识。

## 快捷链接、隐私与生命周期

首页复用已认证的 `GET /api/shortcuts/bookmarks`，自身不写书签文件。2026-11-10 起「管理链接」进入快捷访问的新增/编辑页，写接口与保护见[快捷访问](shortcuts.md)。保存后通过无数据的 `pocket-kit:bookmarks-changed` 事件触发仍挂载首页重新加载，卸载移除监听；未挂载时返回首页正常读取最新数据。保留 ICO 与其他已有图标格式，图标加载失败时使用标题首字回退。

快捷链接加载、失败、空列表各有独立状态；加载失败不影响工具入口。刷新按钮重新读取服务器书签，离开首页取消请求，旧请求不回填。书签数据不进入构建产物或浏览器持久化；localStorage 只保存上次工具页的稳定面板 id。

首页与所有卡片通过 Slot effect 管理；首页声明卸载会移除所属扩展卡片。插件卸载时若当前在首页，返回对话，避免残留无效主面板。

## 手机设计

紧凑标题与分组，不用大幅装饰 Hero。手机采用三列工具图标入口（图标、名称，完整说明保留在可访问名称），常用网站两列；桌面工具卡显示简短说明。所有入口触控至少44px，文字可换行，底部处理safe area。继承宿主明暗背景与字体，仅使用本包局部彩色强调，避免全局样式污染；支持键盘焦点，不依赖hover。

视觉与真机验证必须与注册/源码测试分开记录。没有浏览器控制时，不以模拟DOM或示意截图代替当前GUI验收。
