# 连接测速

## 用途与入口

快捷访问菜单 → 连接测速；菜单动作和 `shell.overlay` 浮层条目 id 均为 `network-speed`，依赖 `local.shortcuts.menu.action` 提供入口。不是独立侧栏主面板。

测量当前浏览器到 DSH 服务端的单连接串行 HTTP 应用层吞吐，包含代理、VPN、TLS 与请求开销；不代表网卡峰值、公网带宽或模型速度。延迟是预热后 5 次 HTTP 往返的中位数，波动是相邻往返差绝对值均值；不是 ICMP ping，不报告丢包率。

## API 与数据

路径前缀 `/api/network-speed/`：

| 后缀 | 方法 | 作用 |
| --- | --- | --- |
| `start` | POST | 建立有时限、流量预算的测速会话 |
| `ping` | GET | 请求往返测量 |
| `download` | GET | 随机二进制下载流 |
| `upload` | POST | 流式读取并丢弃，返回确认字节数及耗时 |
| `stop` | POST | 停止会话与活动传输 |

路由通过 Connection 注册，要求 `X-DSH-Speed-Test: 1`；会话请求使用 `X-DSH-Speed-Id`，上传还校验长度、类型和编码。错误返回 `{ error: <code> }` 与相应 HTTP 状态。具体查询参数和协议细节以功能内 server / measurement 实现及测试为准。

不读取用户文件、不持久化历史，上传为生成的随机数据。测试消耗真实流量，不自动或后台运行。每方向约 8 秒、最多 128 MiB，单请求最多 4 MiB；会话最长 45 秒、全局最多 2 个测试、启动冷却 3 秒、每会话最多 2 个活动传输；客户端总限时 40 秒，无进展超时用于释放资源。

## 重要决策

- 测量引擎与 DOM 分离，服务端路由与 DSH 生命周期接入分离，便于独立测试。
- 速率引擎内部使用 Mbps，当前客户端动态显示十进制 KB/s / MB/s；流量使用 KiB / MiB。不要只换单位标签而不换算数值。旧 README 的固定 MB/s 描述已不完全适用。
- 图表为累计平均速率，不是瞬时网卡速率。上传只统计服务端确认完整收到的请求，已提交量不等于已收到量。
- 下载拒绝不匹配或压缩响应，预算按请求预留，取消不退还，避免并发绕过限制。

## 生命周期

停止、关闭弹层、客户端卸载均取消测量；停止请求有独立超时。断网时后端依赖超时清理。Host 卸载取消所有操作并注销路由，注册中途失败也清理已注册路由。前端完成阶段可保留部分结果，重新打开面板重置状态；弹层关闭恢复焦点。
