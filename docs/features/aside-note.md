## 数据与一致性

- 默认服务端路径：`.local/data/aside-note/notes.json`。首次写入才创建；目录 0700、文件 0600，Git 忽略且排除打包。卸载插件不删除数据。
- 快照 version=1，records 按 `[kind,id]` 编码索引，各自含 revision、items、draft（add/edits）、forwarded、seededSessionIds；全局 preferences 有独立 revision。1.7.1 追加 panelWidth（280–720，整数）、panelHeight（0 或240–10000）、sections（open/done 布尔值）。读取1.7.0文件时在内存补默认360/0/{open:true,done:false}，不为升级自动重写私人数据；旧偏好写入请求未带新字段时保留既有值。imports 保存迁移内容摘要，不保存浏览器凭据。
- 同一 DSH 的已认证所有者共享数据，不按浏览器、会话调用者或 DSH 云账号隔离。切换浏览器后登录同一台 DSH、打开同一工作区/会话，即读取相同服务端记录。不是同步到其他 DSH 服务器，也不防服务端磁盘损坏，需保留备份。
- 进程内按绝对路径串行，revision 做 CAS；多个独立 DSH 进程不得同时写同一文件。临时文件独占创建、fsync 后同目录 rename。文件损坏时拒绝读取/写入，不当空清单覆盖。
- 最多 2000 个范围、每范围 1000 条、每条/草稿 10000 字、快照 16 MiB，迁移请求 2 MiB。数据作为 React 文本呈现，不执行 HTML、URL 或命令。不记录私人内容日志。
- 客户端不再持久化任何该功能业务数据或面板偏好。仅内存保留当前输入；草稿与设置输入静默停顿 650ms 后提交，脚注显示保存中/未保存/已同步。尺寸、默认范围与分区偏好也保存在服务端。设置独立串行 CAS，等待确认期间的更新输入保留，远端轮询不会静默覆盖本地未保存设置；冲突后在「数据与迁移」核对并显式重试。服务端确认后才清空新增框或更新正式列表。断网/冲突保留内存输入；离开网页前对未保存状态触发原生提示，不能保证强制关闭、崩溃或断电前的未确认输入存活。
- 面板打开时每 10 秒和窗口获焦刷新；顶部计数每 15 秒刷新，非 WebSocket 实时推送。冲突后停止自动提交，刷新不丢本地草稿，需用户核对再继续编辑，不自动重放删除等动作。超时可能服务端已提交，须先刷新确认，不盲目重复添加。
- 新增「全局 / 工作区 / 会话」三个范围；全局固定标识 `{kind:'global',id:'all'}`，同一DSH所有工作区/会话共享独立清单、草稿和转发标记，不是所有清单的自动汇总，不合并或移动已有记录。没有工作区时显示全局/会话；尚未打开会话时也可从工具箱进入全局，转发仍需有效会话输入框。范围选择保存在服务端，角标跟随所选范围，保持原有默认范围不变。
- 设置新增「显示范围」会话/工作区/全局三个复选开关，保存在 preferences.visibleScopes，默认三项true。前后端均强制完整布尔对象且至少一项true，旧文件缺失字段时仅在内存补全默认值，旧客户端未提交该字段时保留配置。隐藏不删除或合并任何记录、草稿，不构成访问控制；无可用上下文时仍通过已有认证记录路由刷新共享偏好，不显示隐藏范围的内容。
- 当前范围被隐藏时切到其他启用且上下文可用的范围，角标同步跟随；实际可用范围≤1时不展示Tab，设置不因此消失或关闭。若只开工作区但当前无工作区（或只开会话但尚未打开会话），显示空态而不偷偷展示被关闭的全局，并可通过设置恢复。切换范围会收起行内编辑但保留各范围草稿，正在保存的旧范围响应不能关闭新范围的编辑。
- 工作区首次打开时把当前成员会话的服务端便笺折入一次，seededSessionIds 防止删除后再出现；切换范围不清空原会话数据，全局不参与自动播种。

## 原浏览器数据迁移与卸载顺序

1. 用原来记录便笺的浏览器，访问原来同一 DSH 站点（包括协议/域名/端口），刷新后从工具箱进入旁边记；其脚注标明「数据保存在服务端」。
2. 打开齿轮「设置」→「数据与迁移」，点击「迁移原插件浏览器数据」并确认。只读取固定 `dsh.aside-note*` 旧键：会话/工作区记录、草稿、转发标记、快捷键/前缀/默认范围、面板宽高与分区状态；不扫描其他浏览器数据、不读取登录凭据。
3. 后端严格验证后整批原子合并。坏 JSON、版本/条目不合法或超限会整体失败，不截断便笺、不部分保存。已有服务端便笺不覆盖；同 ID 不同内容另存导入副本；相同整批迁移重复点击无效，删除后也不会因同批重导复活。
4. 草稿按原键保留。原插件新增/编辑草稿本来按会话保存，即使当时正在工作区范围编辑，因此请切到「会话」查看；不再属于现有便笺的编辑文本可在「恢复旧编辑草稿」中放入新增框继续编辑。服务端与旧浏览器都有不同草稿时，冲突旧稿另存便笺。已有服务端设置不覆盖。
5. 核对每个使用过的会话/工作区，导出服务端备份；换另一个浏览器登录同一 DSH 再核对。不同浏览器各有独有旧记录时分别迁移，迁移期间不要继续在原插件新增编辑。
6. 确认后再卸载独立 `dsh-aside-note`。本次不自动卸载、停用它，也不清理其 localStorage。服务端无法直接读取另一浏览器的 localStorage；尚未点击迁移不等于旧记录已经转存。

「导出服务端备份」下载完整 version=1 快照，含所有会话/工作区和草稿，请私下保存；不含原独立插件仅存于其他浏览器的记录。当前没有快照上传恢复 UI，灾难恢复需停用此 Host 后备份现文件、校验并由管理员恢复同格式文件，不能把服务端快照当旧插件数据导入。

## API 与安全

通过 DSH Connection 的认证路由 `GET/POST /api/pocket-kit/aside-note`，不另开端口、不允许匿名。

- GET：`kind=global|session|workspace&id=...` 返回记录与 preferences；全局仅接受 `id=all`，其他全局id返回400；`export=1` 返回完整服务端备份（含全局）。偏好 scopeMode 同样支持 global，旧快照/会话/工作区格式保持兼容。
- POST：JSON，必须 `X-Pocket-Kit: 1`；若有 Sec-Fetch-Site，只允许 same-origin / none。由 Connection 额外校验认证、Host/Origin，兼容外部 HTTPS 到内部 HTTP 桥接。
- 普通命令：`{action,scope:{kind,id},revision,...}`；action 为 add（text）、update（id/text/done）、delete（id）、clear、draft（draft）、forward（id/forwarded）、seed（sessionIds）。返回新记录。
- preferences：`{action:'preferences',revision,sendShortcut,forwardPrefix,scopeMode,panelWidth?,panelHeight?,sections?,visibleScopes?}`，返回新设置，独立版本冲突保护。1.7.0 请求保持兼容，新字段有服务端验证。
- import：`{action:'import',data:{sessions?,workspaces?,drafts?,forwarded?,preferences?}}`，不要求旧数据版本号匹配服务端 CAS，内部串行追加；返回 imported / alreadyImported。
- 错误：400 输入不合法、403 CSRF、404 记录不存在、409 版本冲突、413 超限、415 内容类型、500 存储失败。所有响应 no-store/nosniff，异常不回显原内容。
- 请求 20 秒超时；读请求和 UI 定时器在卸载时取消。关闭面板不撤销已接收写入，内存草稿定时保存继续；客户端卸载清定时器/订阅/监听和请求控制器，未保存内存输入不能保证保留。Host 路由由 ctx.effect 释放，文件句柄 finally 关闭。
