# 出门清单

## 用途与入口

入口为首页的出门清单卡片，不再注册侧栏独立按钮；`main` 面板继续使用 `local.outing-checklist`，页面返回按钮回首页。支持添加、编辑、删除、勾选，按通用/爸爸/妈妈/赞赞筛选，只看待准备，按自定义/待准备优先/中文拼音排序，以及确认后重置准备状态。

**当前源码没有搜索功能**，旧 README 的搜索描述不适用。全部成员、自定义排序且未限制待准备时可上下移动条目。顶部进度统计全部成员，不随筛选改变。

## API

`GET /api/outing-checklist` 返回 `{ items, revision }`。`POST` 使用 JSON，要求 `X-Outing-Checklist: 1`，每个修改命令都携带最新 `revision`：

- `add`：`text`、可选 `person`；默认通用。
- `update`：`id`，以及 `text` / `person` / `checked` 中至少一项。
- `delete`：`id`。
- `reset`：保留条目及顺序，全部设为待准备。
- `move`：`id` 与 `direction: up|down`。

写入成功返回新快照。错误包括 400 `invalid_request`、403 `csrf_rejected`、404 `item_not_found`、409 `revision_conflict` / `revision_exhausted`、500 `storage_error`；具体路由还检查方法、类型和请求体大小。后端命令拒绝未知字段；最多 2000 项，文本裁剪后 1–500 字符，当前 UI 输入上限 200。

## 数据与重要决策

默认 `~/.dsh/outing-checklist.json` 保留不变；Host `dataFile` 可指定其他路径。快照包含非负 revision 和 items，每项 `{ id, text, person, checked }`，数组顺序为自定义顺序。

首次读取缺失文件返回空快照，不创建文件；首次写入才落盘。通过同目录临时文件、fsync、原子替换及 0600 文件权限保存；损坏数据拒绝覆盖。该存储由 DSH 所有者共享，不按会话划分。revision 防止陈旧覆盖，队列仅协调同一进程，不支持多个独立 DSH 进程同时写同一文件。

合并安装包不迁移默认清单，不清空原数据。卸载功能不主动删除数据。备份恢复应在停止写入后操作并验证快照，勿让测试写入正式文件。

## 生命周期

Host 通过 effect 注册和注销 API。页面首次加载及重新获得焦点时读取；卸载取消读取并清理 focus 监听。修改有并发锁，409 冲突触发重新读取并显示提示；保存失败保留表单内容，避免丢失输入。客户端卸载后不再更新已卸载组件；不能把页面关闭理解为已经回滚服务器写入。面板所属功能卸载时返回对话。

统一客户端与 Host 独立启停，后端停用时界面仍可存在但会报不可用。

## 验证与限制

合包自动验证覆盖持久化、并发 revision、输入校验、API 与统一客户端注册，详见[迁移记录](../migration.md)。测试没有写入正式清单；自定义 `dataFile` 的 profile 覆盖未确认，使用自定义路径时应先核对配置。真实 GUI 刷新后的入口及移动交互仍需验证。

回归重点：空数据、CRUD、筛选/排序/移动、确认重置、写失败重试、双页面 revision 冲突、损坏文件拒写、重开持久化与卸载；手机四档宽度、长物品名、操作换行、44px 点击区与软键盘见[移动规范](../mobile.md)。
