# Shortcuts（快捷访问）

独立的 DSH Web 插件：在侧栏添加“快捷访问”菜单，点击网站可在新标签页打开；“详情与备注”页展示网址、说明与备注，并支持复制。

## 准备书签

本仓库**不包含私人书签**。安装前在插件目录执行：

```bash
cp bookmarks.example.json bookmarks.json
```

编辑 `bookmarks.json`，它必须是 JSON 数组，每项可包含：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一标识，建议只用不变的英文/数字/连字符 |
| `title` | 菜单中显示的名称 |
| `url` | 打开的网站地址（建议使用 `https://`） |
| `description` | 详情页的简短说明 |
| `notes` | 详情页展示的备注，可留空 |
| `color` | 图标背景色，如 `#3478c9` |
| `iconDataUrl` | 可选的内嵌图标 data URL；留空时用名称首字代替 |

可按需添加其他字段；`bookmarks.json` 已由仓库根目录的 `.gitignore` 忽略。**不要把真实密码、令牌、内网网址或私人备注写进模板、源码、提交记录或截图。** 本插件会将书签通过 DSH 登录保护的接口发送给已登录浏览器；不要把它当成凭据保险库。若需要保护凭据，请勿将它们写入书签文件。

## 安装与运行

1. 确认本地已有 `bookmarks.json`，并保留整个插件目录（本地链接安装依赖它）。
2. 在 DSH Web 的插件管理器中选择安装本地目录，指向此 `shortcuts` 目录，并在 Web 配置中启用 `@local/shortcuts`。
3. 安装前备份 DSH Web 配置，先在隔离环境确认插件能启动；尤其检查 Cordis 插件 ID `shortcut-links` 未被其他插件占用。部署到正式服务时预先准备独立于 DSH 的回滚方式，避免启动失败后无法进入前端。
4. 刷新 DSH Web 页面，展开侧栏查看“快捷访问”；脚本更新需要重新加载插件或重启 DSH。修改 `bookmarks.json` 后重新打开详情页即可读取最新数据。

未提供 `bookmarks.json` 或文件不是合法 JSON 时，插件接口会返回错误，页面显示加载失败。

## 使用

- 展开侧栏：底部显示“快捷访问”按钮，点击弹出菜单；收起时只显示图标。
- 菜单中的网站在新标签页打开；菜单底部可进入“详情与备注”，查看说明、网址、备注并复制。
- 弹出菜单支持点击外部或 Escape 关闭，方向键、Home、End 可导航。
- 详情页点击“返回对话”回到聊天。
